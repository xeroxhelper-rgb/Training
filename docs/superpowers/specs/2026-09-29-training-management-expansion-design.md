# 교육 관리 기능 확장 설계

## 목적

교육 과정과 차수 등록을 실제 업무 흐름으로 연결하고, 수료 결과의 CSV 백업·복원, 직원 중심 통합 검색, PDF 리포트 저장을 제공한다. 기존 Supabase 기반 데이터 모델과 RLS 권한 체계를 유지하면서, 변경된 데이터만 갱신하고 작업 결과를 사용자에게 명확히 보여준다.

## 범위

### 과정 등록

`/courses/new` 화면에서 다음 정보를 등록한다.

- 과정 코드
- 과정명
- 대상 모델
- 과정 설명
- 유효기간(개월)
- 상태(`draft`, `active`, `archived`)
- 수료 기준률

저장 대상은 `training_courses`이며, 저장 후 과정 목록으로 이동한다. 관리자·HR 권한만 생성 및 수정할 수 있도록 RLS 정책을 추가한다.

### 차수 개설

`/sessions/new` 화면에서 다음 정보를 등록한다.

- 교육 과정
- 차수 번호
- 시작일·종료일
- 장소
- 강사
- 정원
- 상태(`planned`, `open`, `closed`, `cancelled`)

동일 과정의 차수 번호 중복을 저장 전에 검증한다. 저장 후 차수 상세 화면으로 이동한다. 수강 직원 배정은 기존 참여자 편집 흐름을 사용하며, 차수 생성과 참여자 배정은 별도 작업으로 유지한다.

### CSV 가져오기/내보내기

기존 수료 CSV 화면을 전체 수료 데이터의 가져오기·내보내기 화면으로 확장한다. 조건은 전체 또는 팀, 교육 과정, 특정 직원, 특정 차수로 구성한다.

백업 CSV의 표준 열은 다음과 같다.

```text
employee_number,employee_name,department_name,
course_code,course_name,session_id,session_number,
status,completion_date
```

내보내기는 선택 조건에 해당하는 데이터를 다운로드한다. 가져오기는 `employee_number + session_id`를 안정적인 식별자로 사용해 행을 검증하고, 변경된 수료 상태·수료일만 반영한다. 직원·과정·차수를 찾을 수 없는 행은 행별 오류로 보존하고 유효한 행은 계속 처리한다. 기존 `import_batches`와 `import_rows` 감사 기록을 활용한다.

### 통합 검색

Supabase의 직원, 부서, 부서 근무 이력, 수료 과정, 미수료 대상 과정을 조합해 검색한다. 입력 키워드는 공백 또는 쉼표로 분리하고 OR 조건으로 처리한다.

검색 대상은 직원명, 사번, 현재 부서, 부서 근무 이력, 수료 과정명, 미수료 과정명, 직급·직무다. 점수는 사번 정확 일치, 직원명 정확 일치, 직원·부서·과정명 포함 일치, 이력·미수료 과정 일치, 다중 키워드 일치 순으로 높게 부여한다. 결과에는 일치한 항목을 표시한다.

### PDF 리포트

분석/리포트의 인쇄 버튼을 서버 생성 PDF 다운로드 버튼으로 교체한다. 서버 엔드포인트는 현재 선택 조건을 받아 제목·생성일·조건 요약·참여자 수·수료자 수·수료율·분류별 표를 포함한 PDF를 생성한다. 한글 폰트를 포함해 브라우저와 운영 환경에서 동일하게 읽을 수 있도록 한다.

## 데이터 및 권한

- 과정 및 차수 생성·수정 RLS 정책을 추가한다.
- 기존 수료 업데이트 및 import 감사 정책과 충돌하지 않도록 정책 조건을 명시한다.
- CSV 가져오기는 인증된 관리자·HR 권한으로 제한한다.
- 서버 액션과 API 입력은 스키마 검증을 거친다.
- 목록 화면은 저장 후 필요한 레코드만 갱신한다.

## 오류 처리

- 필수 입력 누락, 날짜 역전, 중복 차수 번호는 저장 전에 표시한다.
- CSV는 헤더·형식·식별자 오류를 행 단위로 보고한다.
- PDF 생성 실패 시 조건과 재시도 안내를 표시한다.
- 권한 오류는 사용자에게 재로그인 또는 관리자 권한 확인을 안내한다.

## 검증 기준

- 과정 등록과 차수 개설이 실제 Supabase에 저장되고 목록·상세 화면에 나타난다.
- 동일 CSV를 재가져와도 중복 수료 레코드가 생성되지 않는다.
- 검색 키워드별 결과 순서가 점수 규칙과 일치한다.
- PDF 버튼이 파일을 다운로드하고 한글과 표가 정상 표시된다.
- `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`가 모두 통과한다.

## 구현 순서

1. 과정·차수 CRUD와 RLS
2. CSV 공통 포맷 및 내보내기/가져오기
3. Supabase 기반 통합 검색과 랭킹
4. 서버 PDF 생성 및 리포트 연결
5. 통합 검증과 배포 준비
